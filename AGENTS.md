# Instructions for agents

* Always run the benchmarks before making changes, and then again before sending a PR. If the chnage is not an improvement, try again or abandon the idea.
* When creating a PR, **always** include the actual number(s) for any changed solvers in the PR description - both the before and after numbers, as well as the % improvement.
* Similarly, always update README.md to list the new, better number for the changed solver(s).
